# 管理センターの使い方

管理センターは、契約者・ライセンス・請求書・業務APIを一か所で確認する管理者向け画面です。

- URL: `https://2415.jp/license/admin_api.php`
- バックアップ側: `https://backup.2415.jp/license/admin_api.php`
- 対象: `admin:manage` を持つ管理者、運用担当者、閲覧のみのユーザー

## ログインとセッション

1. 管理センターを開き、SSOでログインします。
2. パスキー再認証を求められた場合は、画面の案内に従って認証します。
3. 操作がない状態が30分続くと自動的にログアウトします。
4. 権限のないセクションはメニューに表示されません。表示されない場合は管理者に権限を確認してください。

## コマンドパレット

- `Ctrl+K`（macOSでは `Cmd+K`）でコマンドパレットを開きます。
- セクション名や操作名を入力して移動できます。
- `/` キーでも検索を開始できます。
- `Esc` で閉じます。

## ライセンスの検索と確認

ライセンス一覧では、次の条件で検索できます。

| 項目 | 内容 |
| --- | --- |
| 検索語 | ライセンスID、ラベル、契約者名など |
| 状態 | 有効、停止、期限切れなど |
| 契約者 | tenant IDで絞り込み |
| 製品 | 製品IDで絞り込み |

- 一覧は25件ずつ表示されます。「前へ」「次へ」でページを移動します。
- ライセンスIDまたは行の操作から詳細ドロワーを開くと、端末数、セッション、有効期限、最終確認日時を確認できます。
- 詳細の「このライセンスの端末を表示」から、該当ライセンスの端末一覧へ移動できます。

## 一括操作とCSV出力

1. 一覧のチェックボックスで対象ライセンスを選択します。
2. 選択件数が表示されたら、一括操作または「CSV出力」を実行します。
3. CSV出力は1回につき1〜200件です。
4. 出力ファイル名は `tuti-licenses-YYYY-MM-DD.csv` です。

CSVには管理用の情報が含まれます。共有範囲に注意し、不要になったファイルは削除してください。

## 請求書管理

請求書管理では、請求書の検索、状態の絞り込み、ページ送りができます。

- 上部のカードに、下書き・発行済み・入金済み・無効の件数と入金済み合計が表示されます。
- 請求書番号、契約者名、slugで検索できます。
- 状態は「下書き」「発行済み」「入金済み」「無効」で絞り込めます。
- 一覧は25件ずつ表示されます。
- 請求書番号のコピーボタンで、番号をクリップボードへコピーできます。

請求書の発行・入金・無効化は、操作権限と請求書の状態を確認してから実行してください。

## 業務API実行

業務API実行画面では、管理APIの操作を選んでリクエストを送信できます。

1. 操作を選択します。
2. 必要なリクエスト本文をJSONで入力します。
3. 「実行」を押すか、`Ctrl+Enter` で送信します。
4. 応答の状態（成功・エラー）とJSONを確認します。
5. 必要に応じて「コピー」または「保存」で応答を退避します。

直近5件の実行履歴は、このブラウザの `localStorage` に保存されます。履歴には操作名、HTTPステータス、実行時刻だけを保存し、リクエスト本文や認証情報は保存しません。共用端末では履歴が残る点に注意してください。

## セキュリティと注意事項

- 管理センターは `Referrer-Policy: no-referrer` とCSP nonceで保護されています。
- APIキー、セッションCookie、パスワードをチャットやCSVへ貼り付けないでください。
- 操作内容は監査ログに記録されます。監査ログの検索条件は、監査ログを表示している間だけ表示されます。
- 心当たりのない操作や権限変更を見つけた場合は、対象キーを停止し、管理者へ連絡してください。

## よくある確認

| 症状 | 確認内容 |
| --- | --- |
| ログイン後に画面が戻る | SSOのセッションとパスキー再認証の完了を確認する |
| セクションが表示されない | ログイン中のユーザーに `admin:manage` があるか確認する |
| CSV出力ボタンが押せない | ライセンスを1件以上選択する |
| 一覧が空になる | 検索語・状態・契約者・製品の絞り込みを解除する |
| 実行履歴が消えた | ブラウザのサイトデータ削除、または別ブラウザでの操作ではないか確認する |
