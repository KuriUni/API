# My Number Smart Login のSSOセットアップで困ったとき

更新 2026-11-06

## まず確認すること

8888フォルダーの `START-SSO-SETUP.cmd` からセットアップを起動してください。通常の起動対象は `installers/current/` にある現在のインストーラー1つです。日付付き候補や `archive` 内のEXEは通常利用向けではありません。

セットアップが途中で止まったPCでは、旧アンインストール登録や `FirstInstallPendingSso` が残っている可能性があります。現行インストーラーはアプリ本体と保護されたライセンス情報を確認し、両方が無い場合は初回インストールとして扱います。

## SSOログインとキー発行の流れ

1. `START-SSO-SETUP.cmd` を実行します。
2. 表示されたSSOログイン画面でSSO IDを入力し、パスキーで認証します。
3. 画面に表示される利用条件と価格を確認して同意します。
4. 利用規約 v2.0 の内容を確認し、JPKIカードで署名します。キーは契約ごとに1つ発行されます。
5. 発行されたキーでオンライン認証を行い、アプリをPCへ配置します。

途中で閉じた場合は、中途半端な状態のまま進めず、`START-SSO-SETUP.cmd` からやり直してください。SSOログインだけではキーは発行されません。発行には契約と権限が必要です。

## セットアップが進まない場合

- 起動対象が `installers/current/` の現行EXEか確認します。
- 旧アンインストール登録だけが残っていないか確認します。
- 既存の保護ライセンス情報がある場合は、再インストールで上書きせず、再認証の手順を使います。
- セットアップ中にエラーが出た場合は、表示された文言と発生した段階を控えてください。

## HTTP 404が表示される場合

HTTP 404は、SSOのログイン画面ではなくAPIの接続先が想定と違う場合にも表示されます。管理APIの接続先が `/license/mobile-manager/admin-auth.php`（本番）になっているか、テスト用の `/license/python-migration/...` が残っていないかを確認してください。配備先のFastAPIのパス、Cookieのスコープ、リバースプロキシの転送先も確認します。

## `FirstInstallPendingSso` が残っている場合

セットアップが中断したWindowsでは、`FirstInstallPendingSso` などが残っていることがあります。現行の `START-SSO-SETUP.cmd` から再実行してください。アプリ本体と保護ライセンス情報が無ければ初回インストールとして扱われ、既存ライセンスがある場合はその状態を保持します。手動でレジストリを削除しないでください。
