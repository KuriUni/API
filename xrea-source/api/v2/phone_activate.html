DEVICE ACTIVATION

電話認証API v2

メールアドレスへ確認コードを自動送信し、入力されたコードを検証して端末セッションを発行する2段階認証です。

REST API · v2.0
1認証を申請メールアドレスへ6桁の確認コードを自動送信
2確認コードで有効化メールに届いたコードを送信して照合

電話認証をターミナルから試す

Macの「ターミナル」でコマンドを実行します。申請すると入力したメールアドレスへコードが届きます。

  1. 1. 申請コマンドを実行ライセンスキーと受信可能なメールアドレスを入れてReturn。
  2. 2. メールを確認届いた6桁コードと応答のrequest.installation_idを控えます。
  3. 3. コードを送信2つ目のコマンドを実行。成功すると端末セッションが発行されます。

① 申請（URL・POST・JSONヘッダー・本文を指定済み）

curl -sS -X POST 'https://2415.jp/license/api/v2/phone_activate.php' \
  -H 'Content-Type: application/json' \
  -d '{
    "api_action": "phone_request",
    "license_key": "ここを発行済みライセンスキーに置き換える",
    "email": "you@example.com",
    "device_fingerprint": "PC-001-UNIQUE-ID",
    "device_label": "PC-001",
    "app_version": "1.0.0"
  }'

② コード確認と有効化

curl -sS -X POST 'https://2415.jp/license/api/v2/phone_activate.php' \
  -H 'Content-Type: application/json' \
  -d '{
    "api_action": "phone_confirm",
    "installation_id": "申請応答のrequest.installation_id",
    "confirmation_code": "メールに届いた6桁の確認コード",
    "device_fingerprint": "申請時と同じ端末ID"
  }'

成功の目印: 申請ではsuccess: trueとrequest.installation_id、email_maskedが返り、確認コードはメールで届きます。有効化ではsession.access_tokenとsession.refresh_tokenが返ります。コードとトークンは他人に見せないでください。

リクエストを作成・送信

電話認証APIはPythonへ移植済みです。申請にはテスト用DBとSMTP設定が必要です。現在、このテスト環境には未設定です。
