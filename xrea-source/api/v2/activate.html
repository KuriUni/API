LICENSE OPERATIONS

ライセンスAPI v2

ライセンスキーで端末を認証し、端末単位のセッションを管理するAPIです。認証後はアクセストークンを使って状態を確認し、更新トークンでセッションを更新します。

REST API · v2.0
1端末を認証ライセンスキーと端末識別子を送信
2セッションを確認アクセストークンで利用状態を確認
3セッションを更新更新トークンで継続利用

まずはMacの「ターミナル」で認証を試す

JSONをどこかの画面に貼るのではなく、下のコマンドをターミナルへ貼り付けてAPIへ送信します。実際のライセンスキーに置き換えてください。

  1. 1. ターミナルを開くMacの「アプリケーション」→「ユーティリティ」→「ターミナル」
  2. 2. 値を置き換えるlicense_keyを発行済みキーに変更。端末ごとに同じdevice_fingerprintを使います。
  3. 3. 実行して結果を見るコマンドを貼り付けてReturn。成功するとsuccess: trueとセッション情報が返ります。

送信内容（URL・POST・JSONヘッダー・本文を指定済み）

curl -sS -X POST 'https://2415.jp/license/api/v2/activate.php' \
  -H 'Content-Type: application/json' \
  -d '{
    "api_action": "activate",
    "license_key": "ここを発行済みライセンスキーに置き換える",
    "device_fingerprint": "PC-001-UNIQUE-ID",
    "device_label": "PC-001",
    "app_version": "1.0.0"
  }'

成功後: 応答のsession.access_tokenは状態確認に、session.refresh_tokenはセッション更新に使います。実際のトークンは他人に見せないでください。APIクライアントへ組み込む場合は、次の各操作のJSON本文を同じURLへPOSTします。

リクエストを作成・送信

値を入力するとJSON本文を作成します。送信先はこのテストサイトです。テスト用DBが未設定のため、現在は書き込み操作が拒否されます。

    i
    トークンの取り扱い
    アクセストークンと更新トークンは認証情報です。平文ログや共有ストレージへ保存せず、安全な端末ストレージで管理してください。旧 /license/api/activate.php もこのv2処理へ転送されます。
